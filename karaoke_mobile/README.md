# 📱 Karaoke Mobile (Android)

Современное мобильное приложение для разметки караоке, выравнивания слогов через **Montreal Forced Aligner (Google Colab)** и настройки динамических бёрст-эффектов с плавной синусоидальной пульсацией.

Проект изолирован в папке `karaoke_mobile/` и готов к автоматической сборке в APK на **GitHub Actions**.

---

## 🌟 Возможности приложения

1. **☁️ Интеграция с Google Colab (MFA)**:
   - Вся тяжелая обработка (Montreal Forced Aligner, Kaldi, акустические модели русского, английского и японского языков) вынесена в бесплатный Google Colab.
   - В мобильном приложении есть встроенный экран подключения: достаточно вставить ссылку на запущенный блокнот (Cloudflare туннель) и нажать «Выровнять».
   - Выровненные слова и тайминги сразу подгружаются в мобильный редактор.

2. **📝 Тач-редактор слогов и бёрстов**:
   - Интерфейс, адаптированный под сенсорный экран смартфона.
   - Удобное переключение статуса бёрста в 1 касание (чип 🔥).
   - Отображение длительности каждого слога в миллисекундах и расчет SPS (слогов в секунду).
   - Автоматическая транслитерация ромадзи.

3. **🎨 Дизайнер бёрста и живой превью (Live Preview)**:
   - Интерактивный виджет в реальном времени демонстрирует перелив текста на экране телефона.
   - Режимы:
     - **Динамическая пульсация (Dynamic Pulse)**: непрерывная синусоидальная волна между оттенками ($factor = 0.5 \times (1 - \cos(2\pi \cdot f \cdot t))$) с квантованием 30 мс, интерполируемая в 60 FPS.
     - **Градиент по кубу (Gradient)**: интерполяция по граням RGB-куба без провалов в серый цвет.
     - **Чередование (Alternate)**: чередование базового и альтернативного цветов.
     - **Одиночный (Single)**.
   - Регулировка частоты пульсации в Герцах и BPM.
   - Выбор базового и альтернативного цветов, смещение оттенка Hue.

4. **📤 Экспорт и шеринг**:
   - Экспорт готового `.ass` файла с тегами `\t`, готового к открытию в VLC, mpv или Aegisub.
   - **Экспорт отрывка аудио (бёрст)**: вырезка аудиофрагмента бёрста для отправки в мессенджеры на согласование.
   - Параметры видеорендера (60 FPS, оверлей карточки SPS counter).

## 🚀 Как запустить и протестировать локально на ПК

Приложение написано на **Flet** (движок Flutter для Python), поэтому его можно запустить на компьютере прямо сейчас — оно откроется в окне с пропорциями мобильного экрана:

```bash
cd karaoke_mobile
pip install -r requirements.txt
python src/main.py
```

## 🤖 Сборка APK на GitHub Actions

Сборка происходит автоматически в облаке GitHub:

1. Запушьте репозиторий на **GitHub**.
2. Перейдите во вкладку **Actions** в репозитории на GitHub.
3. Выберите воркфлоу **Build Android APK (Karaoke Mobile)** и нажмите **Run workflow** (или создайте git-тег, например `v1.0.0`).
4. GitHub Actions развернёт окружение с Android SDK/NDK, скомпилирует приложение и прикрепит готовый файл `KaraokeMobile-APK` в артефакты сборки.
5. Скачайте `.apk` на смартфон и установите!

## ☁️ Как использовать MFA через Google Colab

1. Откройте файл `karaoke_mobile/colab/colab_mfa_server.ipynb` в [Google Colab](https://colab.research.google.com).
2. Выберите **Среда выполнения -> Выполнить всё** (`Ctrl + F9`).
3. В последней ячейке появится ссылка Cloudflare (например, `https://random-words.trycloudflare.com`) и QR-код.
4. Откройте Karaoke Mobile на телефоне во вкладке **Colab MFA**, вставьте ссылку и нажмите **Проверить**.
5. Выберите аудио и текст, нажмите **Выровнять через Colab MFA** — через несколько секунд слова с таймингами появятся в редакторе!
