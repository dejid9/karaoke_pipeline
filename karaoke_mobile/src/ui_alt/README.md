# Альтернативный интерфейс Karaoke Mobile (`ui_alt`)

В этой директории создается альтернативная реализация мобильного интерфейса для модели **Claude Opus 4.6 (Thinking)**.

## Структура
- `components/`: Вспомогательные виджеты (например, `audio_timeline.py`).
- `views/`: Экраны приложения (например, `editor_view.py`, `sps_view.py`).

## Переключение между интерфейсами
Приложение `karaoke_mobile/src/main.py` поддерживает два режима:
1. **Основной (Classic UI)**: загружается из `ui/` (по умолчанию).
2. **Альтернативный (Alt UI)**: активируется установкой переменной окружения `KARAOKE_UI_ALT=1` или через тумблер в диалоге настроек экрана («Настройки экрана и DPI»).

Если какой-либо экран отсутствует в `ui_alt/`, `main.py` автоматически подгружает стандартную реализацию из `ui/` без падения приложения.
