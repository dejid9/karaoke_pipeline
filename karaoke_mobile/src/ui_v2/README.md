# Karaoke Editor V2

`ui_v2` is a touch-first Flet editor kept isolated from the existing application
until it is ready to replace it. It calls the existing `core.ass` and
`core.editor` APIs directly; no karaoke algorithms are duplicated.

## Architecture

- `app.py` — responsive Flet composition, aspect-ratio letterboxing and safe area.
- `editor.py` — editor state, undo/redo snapshots and thin calls into `core.editor`.
- `timeline.py` — custom-painted overview/detail timeline plus touch interaction.

The timeline uses a Flet `GestureDetector` over a `Canvas`: pan scrolls time,
two-finger scale changes zoom, tap selects a syllable, double tap requests
syllable playback, and dragging close to a syllable boundary redistributes it.
Heavy audio assets remain generated by the existing core and can be supplied to
the canvas renderer as pre-rendered images in the next integration pass.

## Run

From the project root:

```bash
flet run src/ui_v2/app.py
```

The app starts with a small editable ASS document. Use **ASS…** to load a file
and **Save ASS** to save the current document.

## Android APK

The chosen stack is **Flet**: it retains direct Python imports from `src/core`,
has Flutter rendering plus Material mobile controls, and packages with Flet's
Android build tooling:

```bash
flet build apk --module-name ui_v2.app
```

The project must be built in an Android-capable environment with the Flet/Flutter
build prerequisites installed. File selection and saving depend on platform
permissions already declared in the root `pyproject.toml`.
