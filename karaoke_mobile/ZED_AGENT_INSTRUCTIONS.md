Ты — ведущий мобильный разработчик и архитектор мобильных интерфейсов.
Твоя задача — спроектировать и написать с нуля современный, эргономичный мобильный интерфейс для караоке-редактора `karaoke_mobile`, обладающий функциональным паритетом с компьютерной версией программы (`karaoke_gui`).

### 1. Контекст и доступ к коду ПК-версии
Вся кодовая база компьютерной версии уже заботливо скопирована прямо в этот проект:
- `docs/pc_gui_source/app.py` — Главное окно десктопной версии (шапка, транспорт-бар, карточки слогов, док-панели).
- `docs/pc_gui_source/timeline.py` — Двухуровневый таймлайн (миникарта песни + детальный холст с вейвформой, спектрограммой и слогами).
- `docs/pc_gui_source/keybindings.py`, `sps_graph.py`, `theme.py` — горячие клавиши, график скорости слогов и цветовые палитры.
- `PC_REFERENCE_GUIDE.md` — Подробный справочник зон, кнопок и методов компьютерной версии.

Вся бизнес-логика (парсинг ASS субтитров, сдвиги, деление и слияние слогов, генерация вейвформ и спектрограмм) реализована на чистом Python и находится в `src/core/`:
- `src/core/ass.py` (`AssDocument`, `KaraokeSyllable`)
- `src/core/editor.py` (`split_syllable_at_time`, `merge_syllables`, `shift_syllable`, `colour_burst`, `insert_after`, `delete_syllable`, и др.)
- `src/core/media.py` (`render_waveform_bmp`, `load_waveform`)
- `src/core/spectrogram.py` (`render_spectrogram_bmp`, `load_spectrogram`)
- `src/core/sps.py` (`render_sps_graph_bmp`, `MeasurementTimeline`)
**Ядро в `src/core/` трогать и переписывать НЕ нужно — используй его напрямую!**

### 2. Свобода выбора фреймворка / стека
Ты волен самостоятельно выбрать лучший фреймворк для мобильного UI:
1. **Flet (Python + Flutter Engine)** — быстрота разработки, 100% Python, прямой импорт `src/core/`, сборка через `flet build apk`.
2. **Kivy / KivyMD** — 100% Python, прямой рендеринг на OpenGL ES (высочайшая точность таймлайна и жестов), сборка через Buildozer.
3. **Flutter (Dart) + Python bridge (serious_python / Chaquopy)** — лучшая в мобильной индустрии отзывчивость и плавность (120 FPS).
4. **HTML5 / Vue / React + Capacitor / Tauri Mobile / WebView** — легкая верстка, HTML5 Canvas для волны, мгновенное тестирование.

*Требования к выбору:*
- Возможность реальной сборки в Android APK.
- Бесшовная связь с алгоритмами `src/core/`.
- Высокая плавность таймлайна (горизонтальный скролл, pinch-to-zoom, перетаскивание границ слогов).
В ответе кратко обоснуй свой выбор фреймворка.

### 3. Обязательные требования к мобильному интерфейсу

#### А. Эмуляция соотношений сторон экрана (Рамки / Letterboxing)
У мобильных устройств бывают разные пропорции экранов (от классических 16:9 и 18:9 до 19.5:9, 20:9 и планшетных 4:3 / 16:10).
- Реализуй переключатель соотношения сторон в шапке или настройках:
  `[Полный экран] | [20:9] | [19.5:9] | [18:9] | [16:9] | [4:3]`.
- При выборе режима приложение должно эмулировать выбранный экран: центрировать рабочее окно с заданными пропорциями и добавлять черные рамки (letterbox/pillarbox) по бокам или сверху/снизу.

#### Б. Регулировка DPI / UI Scale в настройках
- Предусмотри системный коэффициент масштабирования интерфейса `dpi_scale` (например, пресеты `70%`, `80%`, `90%`, `100%`, `115%`, `130%` или слайдер).
- Все шрифты, отступы, высоты кнопок и таймлайна должны умножаться на этот коэффициент, чтобы пользователь мог уместить больше элементов на компактном экране или сделать кнопки крупнее под большие пальцы.

#### В. Паритет функций с ПК-версией:
1. **Транспортная панель:**
   - Play, Pause, Stop с возвратом к старту.
   - Метки диапазона: `[|←]` (Start In), `[→|]` (Stop Out), `[|▶]` (Play from In), `[▶|]` (Play to Out), `[|▶|]` (Play Range), `[↔]` (Диапазон по слогу), `[×]` (Сброс меток).
   - Скорость воспроизведения (таблетки `0.5x`, `0.75x`, `1.0x`, `1.25x`, `1.5x`).
   - Аудио-слой: переключение между волной, спектрограммой и обоими слоями.
2. **Таймлайн для сенсорного экрана:**
   - Миникарта сверху (обзор всей песни) + детальный зумируемый холст.
   - Отображение аудиоволны и цветных прямоугольников слогов с текстом внутри.
   - Жесты: свайп для скролла, pinch-to-zoom для масштаба времени, тап по слогу для выбора, двойной тап для прослушивания, драг границ слога для точной подгонки тайминга.
3. **Карточка активного слога:**
   - Номер слога, время начала/конца, длительность в миллисекундах.
   - Кнопка воспроизведения только этого слога `[▶ Слог]`.
   - Кнопки перехода `[←]` и `[→]`.
   - Редактирование текста слога на лету.
   - Романизация (Manual romanize + поле над слогом).
   - Кнопка `[✂ Разделить по курсору]` (разрез слога в текущей позиции воспроизведения).
   - Кнопка `[[Непроизнесённое]]` (исключение из SPS анализа).
4. **Карточка действий и тайминга:**
   - Вставка нового слога (`insert_after`).
   - Разделение слога 50/50 (`split_syllable`).
   - Объединение слогов (`merge_syllables`).
   - Удаление слога (`delete_syllable`).
   - Выбор типа тега (`\k`, `\kf`, `\ko`, `\K`) и кнопка применения.
   - Undo / Redo и Сохранение `.ass`.
   - Окраска в Burst (`colour_burst`), снятие окраски и экспорт аудио-отрезка слога в WAV.
   - Окно со списком всех строк песни для быстрой навигации.

#### Г. Адаптивность (Ландшафт и Портрет)
- **Ландшафтный режим:** Слева большой таймлайн и транспорт, справа док-панели слогов и действий.
- **Портретный режим:** Сверху таймлайн, по центру транспорт, внизу переключаемые вкладки (`[📝 Слог]`, `[⚙ Действия]`, `[📑 Все строки]`, `[📊 SPS]`).
- Обязательно соблюдать системные отступы (Safe Area / Notch).
