## 2. Полный список функций компьютерной версии (ПК-паритет)
Используй этот перечень, чтобы внедрить максимум полезных возможностей в мобильный интерфейс:

### 2.1. Управление аудио и плеер (Транспорт)
- **Play / Pause / Stop**: воспроизведение и пауза либо остановка с возвратом к начальной точке.
- **Проиграть слог (`▶ Слог`)**: моментальное воспроизведение времени звучания только текущего выбранного слога.
- **Метки диапазона воспроизведения (Playback Limits)**:
  - `|←` (`[I]`): установить метку начала диапазона.
  - `→|` (`[O]`): установить метку конца диапазона.
  - `|▶|`: зацикленное/разовое проигрывание строго между метками диапазона.
  - `|▶`: проиграть от метки старта до конца.
  - `▶|`: проиграть от текущей позиции до метки конца.
  - `↔`: установить обе метки точно по границам выбранного слога/слогов.
  - `×`: сбросить обе метки диапазона.
- **Скорость воспроизведения**: регулировка скорости (от 0.25x до 2.0x, пресеты `0.5×`, `0.75×`, `1.0×`, `1.25×`, `1.5×`).
- **Preserve pitch**: сохранение высоты тона звука при изменении скорости.
- **Возврат к старту**: возврат курсора в точку старта после остановки.

### 2.2. Аудио-визуализация и таймлайн
- **Три режима аудио-слоя**:
  1. `Waveform` — амплитудная огибающая звука.
  2. `Spectrogram` — спектрограмма частот (FFT) с цветовой тепловой картой.
  3. `Both` — совмещенный режим (вейвформа поверх спектрограммы).
- **Спектрограмма**: пресеты голоса («Средний голос», «Низкий», «Высокий») и перестроение спектра.
- **Интерактивный таймлайн**: масштабирование зума (пикселей на секунду), панорамирование (скролл/драг времени), перемещение курсора воспроизведения тапом.
- **Границы караоке-слогов**: наглядные плашки/метки каждого слога на таймлайне с подсветкой активного/выделенных.
- **Индикация состояний слога**: подсветка непроизнесенных слогов и burst-окраски (красный акцент) прямо на таймлайне.

### 2.3. Редактирование слогов и текста караоке
- **✂ «По курсору» (`split_karaoke_at_cursor`)**: деление слога на два ровно по времени курсора плеера (`split_syllable_at_time`).
- **«Разделить» (`split_karaoke`)**: разбиение слога на части по символам текста (`split_syllable`).
- **«Совместить / Слить» (`merge_karaoke`)**: слияние нескольких выделенных слогов в один общий (`merge_syllables`).
- **«Вставить» (`insert_karaoke`)**: вставка нового пустого слога после выбранного (`insert_after`).
- **«Удалить» (`delete_karaoke`)**: удаление слога (`delete_syllable`).
- **Множественное выделение (Multi-selection)**: выбор нескольких слогов (тапом с режимом выбора, чекбоксами или диапазоном) для пакетного слияния или сдвига.
- **Компактная точная подстройка тайминга**: кнопки с шагами (`-10ms`, `+10ms`, `-50ms`, `+50ms`, `-100ms`, `+100ms`) для старта/конца слога и сдвига всего слога во времени (`shift_syllable`).
- **Смещение границы между слогами (`redistribute_boundary`)**: изменение общей границы между двумя соседними слогами без сдвига остальных.
- **Редактирование текста слога**: ввод и редактирование слога.
- **Ручная романизация (Romanization)**: поле «Над слогом» для транскрипции/ромадзи (`set_syllable_romanization`).
- **Типы тегов караоке (`set_tag_type`)**:
  - `\k` — резкое переключение слога без скролла.
  - `\kf` — плавное закрашивание слога слева направо.
  - `\ko` — outline (контурное) караоке.
  - `\K` — псевдоним `\kf`.
- **Пометка «[Непроизнесённое]»**: исключение слогов в скобках `[...]` из голосового анализа.
- **Навигация**: кнопки перехода к предыдущему (`←`) и следующему (`→`) слогу.
- **Редактор «Весь текст…»**: модальное окно со всеми строками и слогами песни для быстрого обзора и пакетной правки.
- **История изменений**: Undo (Отмена) и Redo (Повтор).

### 2.4. Анализ скорости пения и Burst (SPS Workbench)
- **Окраска Burst (`colour_burst`)**: маркировка скоростных партий песни красным цветом.
- **Снятие окраски Burst (`uncolour_burst`)**.
- **Экспорт аудио-вырезки**: сохранение аудио выбранного слога или burst-фрагмента в отдельный WAV.
- **Интерактивный график SPS (SPS Graph)**: отображение кривой скорости пения (слогов в секунду) по времени.
- **Выбор источника SPS**: расчет по времени ASS-субтитров, по точным измерениям (measurements) или оба источника одновременно.
- **Сглаживание кривой SPS**: настройка сглаживания графика.
- **Таблица сегментов скорости**: список участков с параметрами Start, End, Peak SPS, Mean SPS и текстом.
- **Экспорт графика SPS**: сохранение в PNG (16:9) и CSV.

### 2.5. Точные измерения (Measurements)
- Разделение формального субтитрового тайминга и физического акустического звучания слога.
- Корректировка точных акустических границ звука.
- Сброс измерений к границам ASS (`reset_measurement`).
- Импорт и экспорт measurements в JSON.

### 2.6. Проекты и файлы
- Сохранение и загрузка комплексного проекта `.karaoke` (zip-бандл с аудио, ASS, измерениями, спектрограммой, вейвформой).
- Отдельный импорт и экспорт субтитров ASS.
- Создание пустого ASS-файла.

### 2.7. Оформление и темы
- 14 цветовых тем из ПК-версии (AMOLED, Dark, Nord, Cyberpunk, Forest, Slate и др.).
- Настройки масштаба (DPI), соотношения сторон (20:9, 19.5:9, 16:9) и компактности панелей.

## 3. Специфика мобильного экрана 20:9 и Touch-дизайн

1. **В вертикальной (портретной) ориентации:**
   - Экран узкий по ширине. Кнопки НЕ должны вылезать за левый край экрана.
   - Текст НЕ должен зажиматься в узкие контейнеры (избегай вертикального вытягивания надписи «Караоке редактор» и счетчиков слогов).
   - Используй компактные горизонтальные ряды с `ScrollMode.AUTO`, лаконичные IconButton с подсказками (Tooltip), сегментированные переключатели или нижние шторки (BottomSheet) для второстепенных настроек.
2. **В горизонтальной (ландшафтной) ориентации 20:9:**
   - Экран очень широкий, но низкий по высоте. Если разместить все элементы вертикально друг под другом, на список слогов останется 0 пикселей.
   - **Решение:** Адаптивный 2-колоночный сплит (2-Column Split):
     - **Левая колонка (50-55% ширины):** Таймлайн (спектрограмма/вейвформа), курсор, зум, кнопки транспорта воспроизведения, маркеры In/Out, скорость.
     - **Правая колонка (45-50% ширины):** Скроллируемый список слогов + карточка инспектора выбранного слога с компактными кнопками тайминга (`-10`, `+10`), разделения по курсору и слияния.

## 4. Архитектурный контракт с `main.py`

Точка входа `karaoke_mobile/src/main.py` уже поддерживает флаг `KARAOKE_UI_ALT=1` и использует `ui.view_resolver`.
Если какой-то файл отсутствует в `ui_alt`, приложение автоматически берет стандартную версию из `ui/`.

### Главные файлы для реализации:
- `karaoke_mobile/src/ui_alt/components/audio_timeline.py`
- `karaoke_mobile/src/ui_alt/views/editor_view.py`
- *(Опционально)* `karaoke_mobile/src/ui_alt/views/sps_view.py`

Класс `EditorView` в `karaoke_mobile/src/ui_alt/views/editor_view.py` должен наследоваться от `ft.Container`:
```python
class EditorView(ft.Container):
    def __init__(
        self,
        on_document_changed: Optional[Callable[[AssDocument], None]] = None,
        on_jump_to_sps: Optional[Callable[[str], None]] = None,
        on_audio_loaded: Optional[Callable[[str, bytes, Optional[object], Optional[object]], None]] = None,
    ):
        ...
```

**Обязательные поля и методы `EditorView`:**
1. `self.audio_timeline`: Экземпляр виджета таймлайна с методами/полями:
   - `set_audio(name: str, audio_bytes: Optional[bytes], waveform: Optional[WaveformData], spectrogram: Optional[SpectrogramData])`
   - `center_time: float` (текущая позиция курсора в секундах)
   - `is_playing: bool`
   - `stop_audio()`
2. `self.document: Optional[AssDocument]`
3. `self.selected_syllable_id: Optional[str]`
4. `def _refresh_ui(self):` — обновление интерфейса при изменении данных.
5. `def apply_theme(self, palette: ThemePalette):` — обновление цветов темы.
6. `def set_page(self, page: ft.Page):` — ссылка на страницу Flet.
7. `def get_services(self) -> list:` — возврат сервисов (например, FilePicker).
