# ИНСТРУКЦИЯ ДЛЯ AI-АГЕНТА В ZED: СОЗДАНИЕ МОБИЛЬНОГО ПРИЛОЖЕНИЯ С НУЛЯ

> **ВАЖНО:** Этот каталог (`karaoke_mobile_new/`) является совершенно новым, изолированным проектом. Здесь **НЕТ старых файлов интерфейса** и **НЕТ старого 500-строчного `main.py` с 5 вкладками**. Твоя задача — создать **полноценное законченное мобильное приложение** в файле `main.py` (и вспомогательных модулях внутри этой папки).

## 1. Что доступно в этом проекте:

1. **`core/`** — Готовая бизнес-логика на чистом Python (НЕ переписывать, использовать напрямую):
   - `core/ass.py` — Парсинг и генерация файлов субтитров `.ass` (`AssDocument`, `KaraokeSyllable`, `format_ass_time`).
   - `core/editor.py` — Все операции со слогами (`split_syllable`, `split_syllable_at_time`, `merge_syllables`, `insert_after`, `delete_syllable`, `set_tag_type`, `colour_burst`, `uncolour_burst`, `set_syllable_text`, `set_syllable_romanization`).
   - `core/media.py` — Загрузка аудио и рендеринг звуковой волны в BMP (`load_waveform`, `render_waveform_bmp`).
   - `core/spectrogram.py` — Спектральный анализ и рендер спектрограммы в BMP (`load_spectrogram`, `render_spectrogram_bmp`).
   - `core/sps.py` — Аналитика скорости слогов SPS (`MeasurementTimeline`, `render_sps_graph_bmp`).
   - `core/project_bundle.py` — Работа с файлами проектов `.karaoke`.

2. **`pc_reference/`** — Справка и код оригинальной десктопной ПК-версии (`karaoke_gui`):
   - `pc_reference/PC_REFERENCE_GUIDE.md` — Подробнейшее описание всех зон, кнопок и поведения ПК-версии.
   - `pc_reference/pc_gui_source/app.py`, `timeline.py`, `sps_graph.py`, `theme.py` — Исходный код ПК-версии для точной сверки функционала.

## 2. Архитектурные требования: «Единый мобильный верстак» (Workbench)

Забудь про разделение на 5 разрозненных вкладок внизу экрана. Мобильное приложение должно повторять структуру профессионального верстака десктопной версии, адаптированную для сенсорного экрана:

### Зона 1: Шапка приложения (Header)
- Логотип `KARAOKE // SPS`.
- Статус: `ASS: <имя файла>` или `ASS не загружен`.
- Бейдж счетчика слогов: `[ 42 слога ]` (подсвечивает также burst-слоги).
- Кнопки действий: `[Проект…]` (открыть bundle), `[ASS…]` (открыть .ass), `[Медиа…]` (открыть аудио), `[💾 Сохранить]`.
- Кнопка настроек экрана: `[⚙ Настройки]`.

### Зона 2: Настройки экрана — Эмуляция соотношений сторон (Рамки) и DPI:
В модальном окне по кнопке `[⚙ Настройки]`:
1. **Эмуляция экранов (Letterboxing):**
   - Выбор: `[Полный экран] | [20:9] | [19.5:9] | [18:9] | [16:9] | [4:3]`.
   - При выборе рабочая область центрируется с заданными пропорциями, а по краям экрана появляются чёрные рамки (letterbox/pillarbox). Это позволяет эмулировать любые устройства прямо во время работы.
2. **Масштабирование DPI (UI Scale):**
   - Выбор: `70%`, `80%`, `90%`, `100% (по умолчанию)`, `115%`, `130%`.
   - Динамически масштабирует рабочую область интерфейса, позволяя уместить больше элементов или сделать кнопки крупнее под большие пальцы.

### Зона 3: Панель транспорта (Transport Bar)
- Кнопки управления воспроизведением: `[▶ Play]`, `[⏸ Pause]`, `[■ Stop]`.
- Метки диапазона:
  - `[|←]` (Set In) — ставит метку старта по позиции воспроизведения.
  - `[→|]` (Set Out) — ставит метку окончания.
  - `[|▶|]` (Play Range) — проигрывание строго между метками In и Out.
  - `[↔]` (Range from Syl) — выставляет метки ровно по границам выбранного слога.
  - `[×]` (Clear) — сброс меток.
  - Индикатор диапазона времени: `[ 0:01.20 .. 0:04.50 ]`.
- Скорость воспроизведения: переключатели таблетками `0.5×`, `0.75×`, `1.0×`, `1.25×`, `1.5×`.
- Аудио-слой: переключатель отображения `[Волна]`, `[Спектр]`, `[Оба]`.

### Зона 4: Двухуровневый сенсорный таймлайн
- **Overview (миникарта песни сверху):** обзор всей аудиодорожки с цветными блоками слогов.
- **Detail (детальный зумируемый холст):**
  - Отрисовка аудиоволны (через `core.media`) или спектрограммы (через `core.spectrogram`).
  - Интерактивные блоки слогов с отображением текста внутри.
  - Курсор текущей позиции (Playhead) и цветные линии меток In/Out.
  - Сенсорные жесты: свайп для горизонтального перемещения по песне, тап по слогу для его выбора, двойной тап для прослушивания отрезка слога.

### Зона 5: Нижний док — Карточка 1 («Слог, Текст и Романизация»)
- Заголовок: `Слог #N [0:01.20 – 0:01.80] (600 мс)`.
- Кнопки быстрого управления: `[▶ Слог]`, `[← Предыдущий]`, `[→ Следующий]`.
- Поле редактирования текста слога (с обновлением на лету).
- Поле романизации (фуригана / текст над слогом).
- Кнопка **`[ ✂ Разрезать по курсору ]`** — делит слог ровно в позиции playhead.
- Кнопка **`[ [Непроизнесённое] ]`** — оборачивает текст в скобки `[...]` для исключения из SPS.

### Зона 6: Нижний док — Карточка 2 («Тайминг, Теги, История и Burst»)
- Кнопки тайминга: `[➕ Вставить после]`, `[✂ Разделить 50/50]`, `[🔗 Объединить]`, `[🗑 Удалить]`.
- Переключатель тега: выбор `\k`, `\kf`, `\ko`, `\K` с кнопкой применения.
- История: `[↶ Undo]`, `[↷ Redo]`.
- Блок Burst: статус `Burst: ДА / НЕТ`, кнопки `[🔥 Окрасить в Burst]`, `[Снять Burst]`.
- Кнопка `[📑 Все строки песни]` — диалоговое окно со списком всех строк для быстрого перехода.

### Зона 7: Дополнительные инструменты (MFA автовыравнивание и SPS анализ)
- Вместо громоздких постоянных вкладок открываются по кнопкам в шапке как всплывающее боковое меню (Drawer) или нижняя шторка (BottomSheet).

## 3. Требования к верстке и ориентации:
- **Ландшафтный режим (горизонтально):** Слева таймлайн и транспорт, справа — карточки слога и действий.
- **Портретный режим (вертикально):** Сверху таймлайн и транспорт, внизу переключаемые вкладки (`[📝 Слог]`, `[⚙ Действия]`, `[📑 Строки]`).
- Всегда оборачивать рабочее пространство в `ft.SafeArea`, чтобы вырез камеры (Notch) и панель жестов Android не перекрывали элементы.

---

## 4. Как запустить и проверить:
Входной файл приложения — `main.py`.
Команда запуска:
```bash
python main.py
```
*(Или `flet run main.py`)*.
Все зависимости описаны в `requirements.txt`.
